# 에이전트와 진행하는 예제 작업

사용자가 아래 요청 중 하나를 선택하면 에이전트가 필요한 계정·도구·입력과 승인된 비용 범위를 확인하고 진행한다. 예제 파일은 실행 입력이며 **생성 결과나 품질 보증 샘플은 아니다**. GPU·Google API 호출은 아직 수행하지 않았다.

## 바로 실행할 요청

| 예제 | 사용자 요청 | 준비 | 완료 기준 |
| --- | --- | --- | --- |
| [H3 텍스트](requests/h3-text.json) | “호수 위 돛단배를 10초 영상으로 만들어줘.” | H3 환경 | 최종·미리보기 MP4 다운로드, 길이·디코드·움직임 확인 |
| [H3 이미지](requests/h3-image.json) | “이 이미지를 첫 장면으로 세로 영상을 만들어줘.” | H3, 첫 프레임 PNG | 이미지 정체성·자연스러운 움직임·세로 비율 확인 |
| [H3 참조 영상](requests/h3-reference.json) | “이 영상의 움직임을 참고해 안뜰을 걷는 영상을 만들어줘.” | H3, 사용자가 제공한 MP4 | 참조 동작·카메라 반영 정도를 비교. 정확한 복제는 보장하지 않음 |
| [Krea 이미지](requests/krea-image.json) | “도자기 컵의 아침 제품 사진을 만들어줘.” | 이미지 환경 | PNG 열기·질감·구도 확인 |
| [Ideogram 포스터](requests/ideogram-poster.json) | “‘SLOW MORNING’ 포스터를 만들어줘.” | 이미지 환경 | 문구 철자·읽기 쉬움·제품 형태 확인 |
| [YuE2 노래](requests/yue2-song.json) | “이 가사로 잔잔한 포크 노래를 만들어줘.” | 음악 환경 | FLAC 디코드·가사·노이즈·끝부분 확인 |
| [6칸 무드보드](requests/moodboard.json) | “컵 장면을 6가지 스타일로 보여줘. 내가 고를게.” | 이미지 환경 | 한 이미지 3×2, 같은 장면·구도, 1–6번 선택 |

각 예제는 제출 1건이다. 이미지 예제는 한 장을 요청한다. 재생성은 승인 범위를 확인하며 무드보드에서는 사용자 선택을 기다린다. H3 요청 길이는 유효 프레임 수로 조정될 수 있고, YuE2는 길이 지정이나 무보컬을 보장하지 않는다.

### 공통 실행법

저장소 루트에서 실행한다. 필요한 환경이 없다면 먼저 `uv run python tools/setup_modal.py h3`로 계획을 확인한다. 이미지·음악은 각각 `image`, `music`이다.

```sh
uv run python tools/modal_workflow.py prepare video --request examples/requests/h3-text.json --out ../example-h3-text
# 비용 범위 승인 후 한 번 제출
uv run python tools/modal_workflow.py submit ../example-h3-text
uv run python tools/modal_workflow.py status ../example-h3-text
# completed 이후
uv run python tools/modal_workflow.py download ../example-h3-text
```

Krea·Ideogram·무드보드는 `prepare image`, YuE2는 `prepare music`으로 바꾸고 해당 요청 JSON과 새 출력 폴더를 지정한다. 모든 명령은 같은 Modal 계정·환경을 사용한다. 진행 중이면 같은 폴더를 조회하고 제출을 반복하지 않는다.

**이미지·참조 영상 예제:** 요청 JSON을 저장소 밖 작업 폴더에 복사하고, 그 폴더 기준 `inputs/first-frame.png` 또는 `inputs/motion.mp4`에 실제 입력을 둔다. 또는 JSON의 경로를 실제 절대 경로로 바꾼다. 더미 파일로 GPU 작업을 제출하지 않는다. 입력 매체는 레포에 포함하지 않는다.

## 캐릭터 시트 예제

> “짧은 검은 머리에 둥근 안경을 쓴 30대 한국인 여성 도예가의 캐릭터 시트를 만들어줘. 베이지 작업 셔츠, 인디고 앞치마, 짙은 면바지와 갈색 작업화를 착용해.”

에이전트는 [기본 프롬프트](../prompts/character-sheet.md)의 원문을 읽고 위 인물에 맞게 전체 묘사를 변형한다. 중년 남성·은발·정장 묘사는 남기지 않는다. 왼쪽 큰 얼굴과 오른쪽 정면·측면·후면의 머리 없는 의상 뷰, 회색 배경을 유지한다. 완성된 프롬프트를 이미지 요청의 `prompt`에 넣고 가로 캔버스·`count: 1`로 한 번 생성한다. 얼굴·의상 세 방향·손·신발·여백을 검수한다. 시트 전체를 그대로 H3 장면으로 영상화하지 않는다.

## TTS·스토리보드 예제

> “도자기 컵 소개 내레이션을 차분하게 읽어줘. 목소리 샘플을 먼저 들려주고, 확정한 음성 길이에 맞춰 세 장면을 설계해줘.”

대본: “바쁜 아침에도, 잠깐의 여유는 필요하니까요. 손에 편안하게 감기는 작은 컵. 오늘은 조금 천천히 시작해 보세요.”

1. Google Gemini 3.8 Flash TTS 이용 환경과 별도 비용을 확인한다. 전용 CLI는 이 레포에 없으므로 [TTS 안내](../docs/production-pipelines.md)를 따라 공식 API 호출을 준비한다.
2. 첫 문장만 차분하고 따뜻한 말투로 생성해 사용자가 목소리를 선택하도록 한다.
3. 확정된 목소리로 전체 대본을 생성하고 실제 길이를 측정한다. 목표 초 수에 맞춘다고 과도하게 음성을 가속하지 않는다.
4. 세 문장에 컵의 전경·손잡이 디테일·마무리 제품 장면을 배정한다. 장면별 시간, 화면, 카메라, 자막, 음성 구간을 표로 제시한다.
5. 생성할 클립 수·길이·비용 범위를 확인한 뒤 H3 소재를 준비한다. 정확한 문구는 로컬 편집으로 넣는다.

## 환경 준비 후 추천할 연결 예제: 도자기 컵 상업 광고 영상

환경 구축을 마친 에이전트는 먼저 “도자기 컵 상업 광고 영상을 무드보드부터 내레이션·영상·자막·최종 편집까지 완성해볼까요?”라고 제안한다. 사용자가 이미 승인했다면 바로 이어간다. 사용자 요청 예:

> “도자기 컵 상업 광고 영상을 만들어줘. 먼저 무드보드를 보여주고, 내가 고른 스타일로 내레이션·영상·자막과 최종 편집까지 완성해줘.”

최종 목표는 로컬에서 재생 가능한 광고 MP4 한 편이다. 시작할 때 대상 고객·화면 비율·목표 길이·브랜드 문구를 정한다. 지정이 없다면 가상 브랜드 없는 약 15–20초 세로 광고를 초안으로 제안한다. 제품 효능·수치·가격·실제 브랜드를 임의로 만들지 않는다. 필요한 H3·이미지 환경, Google TTS 접근, 로컬 편집 도구와 예상 호출 수·비용을 점검한다. 음악은 선택 사항이며 상업 사용 가능한 모델·소재만 사용한다. H3 라이선스 보유 여부는 재확인하지 않는다.

- 6칸 무드보드 한 장을 생성하고 사용자의 번호 선택을 기다린다.
- 위 대본·TTS 예제로 음성을 확정하고 스토리보드를 만든다.
- 선택된 스타일의 장면 이미지 또는 텍스트 지시로 필요한 H3 클립을 생성한다. 참조 이미지 편집 기능이 현재 이미지 API에 있다고 가정하지 않는다.
- FFmpeg/ffprobe와 필요한 자막·폰트를 확인한다. 없으면 설치 목적·방법을 제안한다. 사용자가 CapCut 편집을 원하면 클립·음성·자막을 정리해 전달한다.
- 음성 타이밍에 컷을 맞추고 자막을 합성한다. 음악이 필요할 때만 별도 생성·합성한다. H3 원본 오디오와 내레이션을 겹칠지 음소거할지도 정한다.
- 최종 MP4의 비율·길이·디코드·자막·음량을 확인한다. 선택된 도구로 수행하지 못한 편집은 완료했다고 보고하지 않는다.

최종 파일 경로와 실제 길이·해상도, 검수 결과, 남은 수정 사항을 전달한다. 사용자가 이어서 편집할 수 있도록 사용한 클립·음성·자막도 작업 폴더에 보존한다. 광고를 외부에 게시하는 단계는 포함하지 않는다.

무드보드, 음성 샘플, 최종 음성, 장면별 생성은 별도 호출이다. 에이전트는 실행 전에 합계를 제시하며 사용자 선택 전 후속 호출을 미리 실행하지 않는다.
