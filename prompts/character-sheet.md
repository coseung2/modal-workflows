# 캐릭터 시트 기본 프롬프트

사용자가 제공한 원문을 아래에 보존한다. 에이전트는 캐릭터 시트 제작 시 이 프롬프트를 출발점으로 삼아 현재 요청에 맞는 완전한 영어 생성 프롬프트를 작성한다. 원문의 중년 남성·정장을 모든 캐릭터에 그대로 적용하지 않는다.

## 변형 방법

- 사용자 요청에서 캐릭터의 나이대, 성별 표현, 인상, 얼굴·헤어·안경 등 식별 특징, 체형, 의상·신발, 작품의 시각 스타일을 정한다. 지정되지 않은 세부는 맥락에 맞게 제안하며 사소한 항목마다 질문하지 않는다.
- 얼굴·머리 묘사와 체형·의상 묘사는 서로 일치하도록 프롬프트 전체를 수정한다. 예를 들어 젊은 캐릭터라면 은발·중년 피부 묘사를 남기지 않는다. 일러스트 캐릭터라면 사진·피부 질감·필름 묘사도 해당 표현 방식에 맞춘다.
- 기본 구성은 유지한다: 가로 캔버스, 왼쪽 약 절반보다 작은 폭의 큰 정면 얼굴, 오른쪽 같은 크기의 정면·정확한 측면·후면 의상 뷰 3개, 균일한 중간 회색 배경. 사용자가 다른 구성을 명시하면 그 요청을 따른다.
- 왼쪽은 머리카락 정수리부터 턱 아래 짧은 목까지 온전히 보이는 얼굴 클로즈업이다. 오른쪽은 머리·얼굴 없이 목에서 신발까지 보이는 **의상 확인용 시각 자료**이며 머리가 있을 자리는 회색 여백이다. 잘린 사진처럼 머리 위치를 화면 밖으로 보내지 않는다. 이 구조를 실제 영상 속 캐릭터 외형이나 동작 지시로 옮기지 않는다.
- 세 의상 뷰의 원단·패턴·색·재단·체형을 맞추고 발끝까지 넣는다. 불필요한 글자·라벨·로고를 추가하지 않는다.
- 생성 전 완성된 변형 프롬프트와 필요한 호출 수를 정한다. 이미 승인된 생성 범위를 반복 확인하지 않는다. 생성한 시트의 얼굴, 세 방향, 의상 일치, 손·신발·크롭·배경을 검수한다.
- 시트는 정체성과 의상을 설계하기 위한 기준이다. 영상 입력에는 필요에 따라 얼굴·의상 기준을 바탕으로 **머리가 있는 정상적인 캐릭터의 장면별 이미지**를 준비한다. 시트 전체를 한 장면처럼 영상화하지 않는다. 현재 레포의 이미지 API는 텍스트 생성이므로 참조 이미지 편집을 지원한다고 가정하지 않는다.
