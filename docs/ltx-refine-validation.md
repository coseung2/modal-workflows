# LTX 리파인 실행 검증과 컷 편집 사례

2026-10-07 (Asia/Seoul), 가상 도자기 브랜드 온유 ONYU 예제의 별도 LTX 실행 환경에서 관찰한 기록이다. **현재 이 공개 저장소에는 LTX 배포·호출 코드가 포함돼 있지 않다.** 아래 기록은 이 저장소만 복제하면 LTX를 즉시 실행할 수 있다는 뜻이 아니며, 다른 계정의 인증·모델 볼륨·배포 접근권을 제공하지 않는다.

## 실제 실행 범위

인물·컵·배경 이미지 3장을 Krea 2 Turbo로 생성하고, LTX 2.5 MSR에서 인물·제품 참조 및 배경으로 사용했다. 최종 사용한 영상 클립 4개를 H100에서 각각 리파인했다. 개인 경로·호출 ID·인증 정보·생성물은 공개 저장소에 포함하지 않는다.

| 항목 | 확인한 구성·결과 |
| --- | --- |
| 입력 | 576×1024, 24fps |
| AI 리파인 출력 | 864×1536, 가로·세로 각각 1.5배 |
| 프레임 수 | 121·145·169·241, 각 입력과 동일 |
| 샘플링 | Euler, 3단계, sigmas `0.85, 0.7250, 0.4219, 0.0`, 영상·오디오 CFG 1/1 |
| 모델 | LTX 2.5 22B dev BF16, distilled LoRA 0.5, Licon MSR V1 |
| 업스케일러 | LTX 2.3 spatial x1.5 |
| 오디오 | 오디오 잠재 노이즈 마스크 0, 최종은 입력 오디오 경로 사용. 재인코딩하므로 바이트 동일 보장은 아님 |
| 파일 검사 | 4개 출력의 크기·프레임 수·음성 스트림·전체 디코드 통과 |
| 함수 측정 시간 | 132.02·72.12·81.51·109.45초. 청구 GPU 시간과 다르며 일반 성능 보장이 아님 |
| 최종 편집본 | 1080×1920, 24fps, 480프레임, 20초. 리파인 뒤 편집·글자 합성·출력 크기 조정 |

이전 버전의 1080×1920 출력은 576×1024 생성물의 Lanczos 리사이즈였다. 이후 버전은 위 AI 리파인을 실제 수행했다. **출력 해상도가 같다는 사실만으로 AI 업스케일 수행 여부나 디테일 개선 정도를 판단하지 않는다.**

## 시험 편집에서 발견한 문제

아래 시간은 수정 전 20초 시험본 기준이다.

| 위치 | 화면 증거 | 원인·대응 |
| --- | --- | --- |
| 3초 | 손잡이에 닿던 손이 다음 컷에서 다시 떨어진 상태 | 컷 길이보다 접촉 단계를 우선해 다음 숏 입점을 이동 |
| 5.5초 | 컵 높이·화면상 크기와 얼굴 구도가 동시에 바뀜 | 물체의 동작 단계와 프레이밍을 함께 비교하고 제품 디테일 숏의 역할을 명확히 조정 |
| 11초 | 컵을 낮추며 입을 벌린 상태에서 높은 컵과 미소로 바뀜 | 입 모양이 바뀌기 전 출점과 컵이 내려가는 단계의 입점을 선택 |
| 엔딩 | 긴 후퇴로 빈 의자가 제품보다 크게 보임 | 후퇴 구도를 조정하고 마지막 4초에 Krea 제품 이미지와 정확한 브랜드 문구를 배치 |

직접 원인은 정해 둔 사용 길이를 우선한 편집과 컷 경계 검수 부족이었다. 별도로 생성된 숏 사이의 시선·조명·구도 변동도 영향을 줬다. 리파인만으로 이 문제를 해결할 수는 없다.

수정 시 전환 직전·직후 프레임을 비교하고 입점·출점과 구도를 조정했다. 최종 파일의 전체 디코드와 음량을 확인했으며 피크 측정은 -1.9 dB였다. **샘플 프레임 검토와 파일 검사를 전체 정상 속도 시청·청취 검수로 대신했다고 주장하지 않는다.** 독립 생성 숏의 시선·조명 차이는 일부 남았다. 실제 마시는 동작·내려놓기 영상과 정지 제품 엔딩 카드의 역할을 구분했다.

## 다음 제작에 적용할 기준

- [연출·편집 지침](direction-and-editing.md)의 컷 경계 검사에 따라 마지막·첫 프레임뿐 아니라 동작 앞뒤와 소리도 검토한다.
- 동일 인물 참조는 손·컵의 시작/끝 상태 고정과 다르다. 사용하는 모델의 시작 프레임·끝 프레임 제어 지원을 확인하고, 지원하지 않는 기능을 프롬프트만으로 보장하지 않는다.
- 입력 이미지의 생성기·역할·해시와 각 영상 호출 ID를 저장소 밖 작업 폴더에 보존한다. 파일 재사용이나 다른 생성기 혼입 여부를 실제 입력으로 확인한다.
- 생성 완료, 리파인 완료, 다운로드, 디코드, 화면 검토, 정상 속도 재생·청취 검수를 별도 사실로 보고한다. 현재 CLI가 컷 연결이나 광고 품질을 자동 판정하는 것은 아니다.
