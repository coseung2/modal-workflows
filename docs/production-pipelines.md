# 대화로 진행하는 추천 제작 흐름

사용자는 원하는 결과를 말하고 에이전트가 실행 방법과 필요한 도구를 제안한다. 매 작업에 모든 단계를 강제하지 않는다. 이 문서는 제작 순서 가이드이며 별도의 산출물 관리·레퍼런스 수집 시스템을 설치하게 하지 않는다.

## 만들 수 있는 것

| 요청 | 에이전트의 작업 |
| --- | --- |
| “이 이미지로 10초 영상을 만들어줘” | H3 이미지 입력으로 생성하고 파일 회수 |
| “이 동작을 참고해서 영상을 만들어줘” | H3 참조 영상 입력과 프롬프트 설계, 결과 비교 |
| “같은 인물이 나오는 짧은 이야기를 만들어줘” | 캐릭터 시트·장면 이미지·스토리보드·음성 설계 후 클립 생성·편집 |
| “내레이션과 자막이 있는 설명 영상을 만들어줘” | 대본·TTS·장면 구성·영상 소재 생성 후 로컬 합성 |
| “제품 소개 영상을 세로로 만들어줘” | 제품 자료·문구 확인, 시각 방향·장면 설계, 클립 생성, 로컬 문구·음악 합성 |

현재 H3는 한 번에 1–15초를 요청할 수 있다. 5초는 기본 예시일 뿐이다. 24fps의 유효 프레임 수로 길이를 올림하므로 실제 길이는 다를 수 있다. 긴 영상은 장면별로 생성하고 로컬에서 연결한다. 장면 연결이나 참조 입력이 캐릭터·동작의 완벽한 일관성을 보장하지 않으므로 검수한다.

## 단계 선택

| 단계 | 설계할 내용 | 사용자 검토 지점 |
| --- | --- | --- |
| 목적·분량 | 시청 대상, 내용, 비율, 길이, 납품 형식 | 무엇을 만들지 |
| 무드보드 | 구별되는 색감·화풍·조명·재질·분위기 방향 | 어떤 방향을 쓸지 |
| 캐릭터 시트 | 얼굴·헤어·체형·의상과 세 방향 의상 뷰 | 캐릭터 기준 |
| 대본 | 실제 대사·내레이션·정보 순서 | 전달할 내용 |
| 스토리보드 | 장면별 목적·화면·동작·카메라·길이·전환·음성 | 장면 구성 |
| TTS | 목소리·속도·감정·발음·쉼 | 짧은 샘플 |
| 생성 | 확정된 입력으로 이미지·영상·음악 생성 | 사용할 결과 선택 |
| 편집·검수 | 컷·음성·음악·자막 합성, 파일 검사·시청 | 최종 결과 |

캐릭터 시트는 반드시 [사용자 제공 기본 프롬프트](../prompts/character-sheet.md)를 읽고 캐릭터에 맞게 변형한다. 중년 남성·정장이라는 예시 특징은 고정 조건이 아니다. 무드보드는 여러 방향을 비교하는 자료이고, 스토리보드는 선택된 방향을 실제 장면으로 구체화하는 자료다.

## 추천 조합

- **캐릭터 중심 이야기:** 캐릭터 시트 → 대본·스토리보드 → 필요한 장면별 정상 캐릭터 이미지 → H3 → 음성·편집.
- **내레이션 설명 영상:** 대본 → TTS 샘플·전체 음성 → 실제 음성 길이에 맞춘 스토리보드 → 생성·편집.
- **분위기·뮤직 영상:** 무드보드 → 음악 방향·음원 → 리듬별 장면 설계 → 클립 생성·편집.
- **제품 소개:** 제품 원자료·정확한 문구 → 무드보드 → 스토리보드 → 생성 → 로컬에서 문구·로고·음악 합성.
- **짧은 클립 하나:** 입력·프롬프트·길이 확인 → 생성 → 다운로드·검수. 필요 없는 무드보드·대본 단계를 추가하지 않는다.

## TTS 추천: Google Gemini 3.8 Flash TTS

기본 추천 모델은 `gemini-3.8-flash-tts`다. 말투·속도·감정과 화자별 음성 설계를 지원하는 Google TTS 경로다. 실제 호출 시 최신 공식 입력 형식과 계정에서 사용 가능한 모델·음성을 확인한다. [공식 모델 안내](https://ai.google.dev/gemini-api/docs/models/gemini-3.8-flash-tts), [TTS 사용법](https://ai.google.dev/gemini-api/docs/speech-generation)

이 레포에는 Gemini TTS 전용 호출 CLI가 아직 없다. 에이전트는 사용자의 Google API 인증·이용 가능 도구를 확인하고 공식 API에 맞는 호출 방법을 준비한다. Google 계정·API 키·할당량·과금은 Modal과 별개이며 Modal의 크레딧으로 결제되지 않는다. 없는 키를 요구할 때는 안전한 설정 방법을 안내하고 채팅에 원문을 붙이게 하지 않는다.

1. 대본과 화자를 정하고 목소리·말투·발음 기준을 설계한다.
2. 짧은 샘플로 목소리와 한국어 고유명사·숫자 발음을 확인한다.
3. 선택한 목소리·설정을 유지하며 장면이나 문단 단위로 생성한다. API에는 낭독할 대본과 연기 지시를 공식 형식에 따라 분리한다.
4. 실제 음성 길이를 측정한 뒤 장면 길이와 자막을 맞춘다. 정확한 초 단위 길이가 저절로 보장된다고 가정하지 않는다.
5. 에이전트가 음성·발음·클리핑·침묵 구간을 확인하고 영상과 합성한다.

## 로컬 편집 도구 확인과 추천

에이전트는 최종 결과에 필요한 작업과 현재 도구를 먼저 확인한다. 실행 파일·버전과 실제 조작 가능한 경로를 검사하고, 설치돼 있다는 이유만으로 자동 조작 가능하다고 보고하지 않는다.

- FFmpeg/ffprobe가 있으면 컷 연결·리사이즈·음악 합성·자막 삽입·디코드 검증 등에 활용한다. 자막 필터·폰트 등 필요한 기능도 확인한다.
- 사용자가 CapCut 등 편집기에서 직접 수정하려면 호환되는 클립·음성·자막을 정리해 전달한다. 에이전트 제어 경로가 없으면 직접 편집까지 했다고 보고하지 않는다.
- 필요한 도구가 없으면 작업 목적, 추천 도구, 설치 방법, 비용 여부를 설명한다. 이미 허용된 범위의 설치는 진행하고 유료 구매·구독은 임의로 하지 않는다. 특정 편집기나 After Effects를 필수로 만들지 않는다.
- 기존 작업·프로젝트·앱 설정을 보존한다. 장시간 생성과 편집 전에는 이미 승인된 호출 수·비용 범위를 따른다.

레포가 제공하는 것은 원격 생성·환경 구축 도구다. 로컬 편집과 TTS는 에이전트가 사용자 환경의 도구·서비스를 연결해 수행한다. 자동 편집 기능이 모두 내장돼 있다고 설명하지 않는다.
